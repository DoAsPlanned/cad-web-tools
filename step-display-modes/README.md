# STEP Display Modes

Просмотрщик STEP-файлов с пятью режимами отображения для инженерного анализа деталей.

Использует полноценный парсер OpenCascade (occt-import-js) для загрузки STEP-геометрии и Three.js для рендеринга.

## Возможности

- Загрузка файлов `.step` / `.stp`
- Настоящий парсер STEP через occt-import-js (OpenCascade, WASM)
- Поддержка иерархии узлов STEP
- Пять режимов отображения:
  - **Базовая** — оригинальные цвета STEP, PBR-материалы
  - **Серая с контурами** — серый цвет плюс рёбра геометрии
  - **Прозрачная с контурами** — почти прозрачная (opacity 0.03) с рёбрами
  - **Цветная 30%** — полупрозрачная (opacity 0.3) с сохранением цветов
  - **Светлая техническая (clay)** — стиль clay: белый фон, чёрные жирные контуры, силуэт
- Автоцентрирование модели и подгонка камеры под bounding box
- Управление камерой: вращение, зум, панорамирование
- Адаптив при изменении размера окна
- Корректная очистка памяти при загрузке новой модели

## Режимы и их параметры

| Режим | Цвет | Прозрачность | Контуры | Фон |
|-------|------|--------------|---------|-----|
| Базовая | оригинал STEP | 1.0 | нет | серый |
| Серая с контурами | 0x9ca3af | 1.0 | рёбра | серый |
| Прозрачная с контурами | 0xffffff | 0.03 | рёбра | серый |
| Цветная 30% | оригинал STEP | 0.3 | нет | серый |
| Светлая техническая | 0xffffff | 1.0 | рёбра + жирные + силуэт | белый |

## Как работает технический режим (clay)

Используются три уровня контуров:

1. Обычные рёбра — EdgesGeometry + LineBasicMaterial (порог 20°)
2. Жирные рёбра — LineSegments2 + LineMaterial (управление толщиной в пикселях)
3. Силуэт — кастомный шейдер (onBeforeCompile) на основе нормалей и BackSide

Силуэтный шейдер сдвигает вершины вдоль проекции нормали, создавая чёрную обводку вокруг модели. Толщина зависит от радиуса bounding sphere каждой mesh.

## Запуск

Локальный сервер обязателен — из-за WASM и ES-модулей file:// не сработает.

```bash
npx serve .
```

Или через Python:

```bash
python -m http.server 3000
```

Открой http://localhost:3000

| Зум | Колесо мыши |

### Интерфейс

- Загрузить STEP/STP — выбор файла
- Подогнать — пересчёт камеры под bounding box модели
- 5 кнопок режимов — переключение стиля отображения

## Настройка парсера STEP

В main.js функция createStepObject3D:

```js
const result = occt.ReadStepFile(stepData, {
  linearUnit: 'millimeter',
  linearDeflectionType: 'bounding_box_ratio',
  linearDeflection: 0.0015,   // точность триангуляции
  angularDeflection: 0.3      // угловая точность
});
```

- Уменьшение linearDeflection даёт более точную (и тяжёлую) триангуляцию
- Уменьшение angularDeflection даёт более гладкие скругления

## Стек

- Three.js — рендеринг 3D-сцены
- occt-import-js — парсинг STEP (OpenCascade, WASM)
- OrbitControls — управление камерой
- LineSegments2 / LineSegmentsGeometry — жирные контуры
- ES6 modules через importmap
- Локальные вендоры (./vendor/three, ./vendor/occt-import-js)
