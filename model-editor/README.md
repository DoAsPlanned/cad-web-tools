# 3D Model Editor

Редактор 3D-моделей в браузере: выделение отдельных деталей кликом и их перемещение в пространстве.

Загрузите модель в формате GLB или GLTF, кликните на деталь — она выделится. Дальше её можно двигать мышью через gizmo, кнопками по осям или задать точные координаты.

## Возможности

- Загрузка моделей GLB / GLTF — из файла или по URL
- Клик по детали — выделение через raycasting
- Выделение жёлтым цветом с сохранением исходных материалов
- Перемещение выделенной детали:
  - Мышью через TransformControls (gizmo с осями X/Y/Z)
  - Кнопками пошагового смещения (шаг 0.1 по каждой оси)
  - Точным вводом координат X/Y/Z с кнопкой «Применить»
- Вращение, зум и панорамирование камеры (OrbitControls)
- Автоцентрирование модели при загрузке
- Автоматическая очистка памяти при загрузке новой модели
- Сетка и оси координат для ориентира
- Освещение: ambient + directional (с тенями) + два point light
- Адаптив под изменение размера окна

## Запуск

### Через встроенный сервер

```bash
node server.js
```

Открой http://localhost:3000

### Через npx serve

```bash
npx serve .
```

> Не открывай `index.html` напрямую через `file://` — ES-модули и загрузка моделей не заработают. Нужен HTTP-сервер.

## Управление

### Камера

| Действие | Кнопка |
|----------|--------|
| Вращение | Левая кнопка мыши |
| Зум | Колесо мыши |
| Панорамирование | Правая кнопка мыши |

### Редактирование детали

| Действие | Как |
|----------|-----|
| Выбрать деталь | Клик по ней мышью |
| Снять выделение | Клик по пустому месту сцены |
| Переместить мышью | Тянуть за стрелку gizmo |
| Переместить на 0.1 | Кнопки →X / ←X / ↑Y / ↓Y / ↗Z / ↙Z |
| Задать координаты | Поля X / Y / Z → кнопка «Применить» |

## Стек

- Three.js (ES modules через importmap)
- OrbitControls — управление камерой
- TransformControls — gizmo перемещения
- GLTFLoader — загрузка GLB/GLTF
- Чистый JavaScript, без сборки
- Node.js HTTP-сервер для локального запуска

## Как это работает

### Выделение детали

1. Клик по canvas → координаты переводятся в нормализованные (−1..1)
2. Raycaster пускает луч из камеры через точку клика
3. Ищется пересечение со всеми mesh текущей модели
4. Первый пересечённый объект выделяется: сохраняются исходные цвета материалов, затем материал перекрашивается в жёлтый (0xffcc00)
5. К выделенному объекту прикрепляется TransformControls

### Перемещение

- Мышью: TransformControls даёт gizmo со стрелками по осям. При перетаскивании OrbitControls отключается
- Кнопками: изменение position на 0.1 по соответствующей оси
- Вводом координат: position.set(x, y, z) с обновлением полей

### Автоцентрирование

При загрузке через Box3.setFromObject вычисляется bounding box. Модель масштабируется так, чтобы максимальный размер стал 2.5, и смещается так, чтобы центр оказался в начале координат.

## Ограничения

- Не сохраняет изменения обратно в файл (только визуальное редактирование в сцене)
- Работает только с GLB / GLTF
- Перемещение только позиции — без вращения и масштабирования деталей
- Один выделенный объект за раз

## Поддержка браузеров

Chrome, Firefox, Safari, Edge (актуальные версии). Требуется WebGL 2.0.
