# 2D Annotation Editor

Редактор интерактивных сносок на изображении: расстановка пронумерованных маркеров с указателями, редактирование подписей и автоматическое выравнивание без пересечений.

Разработан для задач САПР и ИЭТР — разметки деталей на фотографиях и схемах.

## Возможности

- Загрузка изображения через кнопку или drag & drop
- Добавление сносок: кругляш с номером и точка-указатель, соединённые линией
- Перетаскивание кругляша и точки мышью
- Редактирование имени сноски в боковой панели
- Подсветка сноски: клик в списке, двойной клик по маркеру или по строке списка
- Удаление сноски с подтверждением
- Автоматическое выравнивание (Smart Align): маркеры расставляются по краям без пересечений линий и наложений
- Сохранение позиций в нормализованных координатах (0..1) — сноски не съезжают при изменении размера окна
- Работает полностью в браузере, без сервера

## Запуск

Открой `annotation_viewer.html` в браузере или через локальный сервер:

```bash
npx serve .
```

Открой http://localhost:3000/annotation_viewer.html

## Как пользоваться

1. Загрузите изображение: кнопка «Загрузить фото модели» или перетащите файл в область просмотра
2. Нажмите «Добавить сноску» — появится маркер с номером и точка-указатель
3. Перетащите кругляш и точку в нужные места
4. Отредактируйте имя сноски в списке слева
5. Двойной клик по сноске — подсветка. Повторный двойной клик — снять подсветку
6. Кнопка «Выровнять (без пересечений)» — автоматическая расстановка маркеров

## Как работает Smart Align

1. Для каждой сноски определяется ближайшая сторона (лево / право / верх / низ) по позиции точки-указателя
2. Сноски группируются по сторонам
3. Внутри группы кругляши расставляются с равным шагом
4. Наложения кругляшей устраняются итеративным расталкиванием
5. Если линии сносок пересекаются, сноска переносится на другую сторону и результат проверяется
6. Процесс повторяется, пока пересечения не исчезнут или не достигнут лимит итераций

## Стек

- Чистый JavaScript (ES6), без зависимостей
- HTML5 Canvas для отрисовки линий сносок
- CSS3 для UI и маркеров
- requestAnimationFrame для плавного перетаскивания

## Управление

| Действие | Что делает |
|----------|-----------|
| Левая кнопка по маркеру | Перетаскивание |
| Двойной клик по маркеру | Подсветка / снять подсветку |
| Клик по строке в списке | Подсветка сноски |
| Кнопка «Добавить сноску» | Создать новую сноску |
| Кнопка «Выровнять» | Автоматическая расстановка |
| Кнопка «Удалить» в строке | Удаление с подтверждением |

## Поддержка браузеров

Chrome, Firefox, Safari, Edge (актуальные версии). Требуется поддержка HTML5 Canvas и File API.
